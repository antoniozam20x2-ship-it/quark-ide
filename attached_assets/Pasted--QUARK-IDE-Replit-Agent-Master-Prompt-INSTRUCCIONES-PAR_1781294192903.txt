## TECH STACK

Frontend:
- React 18 + TypeScript + Vite
- Monaco Editor (@monaco-editor/react) for the code editor
- Tailwind CSS for styling
- PWA enabled (vite-plugin-pwa) — must be installable on mobile

Backend:
- Node.js + Express + TypeScript
- Anthropic SDK (@anthropic-ai/sdk)
- CORS enabled for frontend communication
- dotenv for environment variables

Monorepo structure:
- /frontend  → React PWA
- /backend   → Express API
- /package.json → root with workspaces

## BACKEND API ROUTES

### POST /api/chat
Request:
{
  "messages": [{ "role": "user", "content": "..." }],
  "fileContent": "current editor content as string",
  "fileName": "index.ts"
}

Behavior:
- Prepends system message: "You are QUARK, an expert AI coding 
  assistant. You have access to the current file the user is 
  editing. File: {fileName}\n\nContent:\n{fileContent}\n\n
  When suggesting code changes, always provide the complete 
  modified file content in a code block."
- Calls Anthropic API claude-sonnet-4-6
- Streams response back to frontend
- max_tokens: 4096

Response: streaming text/event-stream

### POST /api/warroom/think
Request:
{
  "idea": "project description",
  "options": {
    "includeTechStack": true,
    "includeDatabase": false,
    "includeUX": true,
    "mode": "MVP Plan"
  }
}

Behavior:
- System: "You are a senior software architect and product 
  strategist. Analyze the project idea and provide a structured
  plan. Format your response with clear sections using these 
  exact headers: ## Project Overview, ## Recommended Architecture,
  ## Database Design, ## UI/UX Recommendations, 
  ## Development Phases, ## Potential Challenges.
  Be specific, technical, and actionable."
- model: claude-sonnet-4-6
- max_tokens: 4096

### POST /api/warroom/board
Request:
{
  "challenge": "what to build or problem to solve",
  "member": "CEO" | "CTO" | "Designer" | "QA"
}

Behavior:
- Uses the role-specific system prompt defined above
- Each member called separately from frontend
- model: claude-sonnet-4-6
- max_tokens: 1024

Response: { "role": "CEO", "response": "..." }

### POST /api/warroom/search
Request:
{
  "query": "search query"
}

Behavior:
- System: "You are a technical research assistant. The user is 
  searching for development-related information. Provide a 
  comprehensive, well-structured answer with code examples where
  relevant. Cite best practices and include practical 
  implementation tips."
- model: claude-sonnet-4-6
- max_tokens: 2048

## RAILWAY DEPLOYMENT

Create railway.json in root:
{
  "build": { "builder": "NIXPACKS" },
  "deploy": { "startCommand": "npm run start" }
}

The backend serves the built frontend as static files in production:
- backend/src/index.ts must serve frontend/dist as static
- All unknown routes return frontend/dist/index.html (SPA routing)
- This means ONE Railway service serves both frontend and backend

Production flow:
1. Railway builds: npm run build (builds both)
2. Railway starts: npm run start (backend serves everything)
3. Single URL for the whole app
