## FIX 2 — agentRouter.ts (análisis degradado en FAST MODE)

El problema: cuando el usuario hace preguntas de comprensión 
("qué significa S6"), el sistema cae en FAST MODE sin haber 
cargado archivos reales, entonces el LLM adivina sin contexto.

En el READ PATH (detectReadIntent === true), el backend manda
done con files: [] aunque sí leyó archivos en readFiles.

Cambiar la línea del send('done') al final del READ PATH de:
  send('done', {
    files: [],
    commitMessage: '',
    mainComponent: readFiles[0]?.path ?? '',
    mainContent: readFiles[0]?.content ?? '',
    repo,
    branch,
    contextSaved: true,
  });

A:
  send('done', {
    files: readFiles.map(f => ({ path: f.path, content: f.content })),
    commitMessage: '',
    mainComponent: readFiles[0]?.path ?? '',
    mainContent: readFiles[0]?.content ?? '',
    repo,
    branch,
    contextSaved: true,
  });

Esto hace que el frontend reciba los archivos reales en result.files,
lo que activa el readFilesRef y muestra el botón War Room.

Solo tocar estos dos archivos. No tocar lógica de War Room ni backend de swarm.
