Necesito persistir el estado del editor cuando el usuario navega entre páginas. El problema: EditorPage se desmonta y pierde todo. La solución: subir el estado crítico a App.tsx.

Sigue estos pasos exactos:

En frontend/src/App.tsx:
Importa el tipo FileEntry desde donde esté definido (búscalo en EditorPage.tsx o en un archivo de types).

Agrega estos 3 estados nuevos junto a los existentes:
const [editorFiles, setEditorFiles] = useState<FileEntry[]>(INITIAL_FILES)
const [editorActiveFile, setEditorActiveFile] = useState<FileEntry>(INITIAL_FILES[0])
const [editorMobileTab, setEditorMobileTab] = useState<'editor' | 'chat' | 'preview' | 'agent'>('editor')

Importa también INITIAL_FILES desde donde esté definido en EditorPage.tsx.

Pasa los nuevos estados a EditorPage:

{page === 'editor' && (
<EditorPage
activeProject={activeProject}
autoShowPreview={agentPreviewPending}
onPreviewShown={() => setAgentPreviewPending(false)}
persistedFiles={editorFiles}
persistedActiveFile={editorActiveFile}
persistedMobileTab={editorMobileTab}
onFilesChange={setEditorFiles}
onActiveFileChange={setEditorActiveFile}
onMobileTabChange={setEditorMobileTab}
/>
)}

En frontend/src/pages/EditorPage.tsx:
Agrega las 6 props nuevas a la interfaz EditorPageProps:

interface EditorPageProps {
activeProject: Project
autoShowPreview?: boolean
onPreviewShown?: () => void
persistedFiles: FileEntry[]
persistedActiveFile: FileEntry
persistedMobileTab: 'editor' | 'chat' | 'preview' | 'agent'
onFilesChange: (files: FileEntry[]) => void
onActiveFileChange: (file: FileEntry) => void
onMobileTabChange: (tab: 'editor' | 'chat' | 'preview' | 'agent') => void
}

Reemplaza los 3 estados locales con los valores del prop:

// ANTES:
const [files, setFiles] = useState<FileEntry[]>(INITIAL_FILES)
const [activeFile, setActiveFile] = useState<FileEntry>(INITIAL_FILES[0])
const [mobileTab, setMobileTab] = useState<'editor' | 'chat' | 'preview' | 'agent'>('editor')

// DESPUÉS:
const [files, setFiles] = [persistedFiles, onFilesChange]
const [activeFile, setActiveFile] = [persistedActiveFile, onActiveFileChange]
const [mobileTab, setMobileTab] = [persistedMobileTab, onMobileTabChange]

Nota: la sintaxis [value, setter] no es un hook — es simplemente usar las props como si fueran estado. El resto del código que llama setFiles(...), setActiveFile(...), setMobileTab(...) no cambia ni una línea — sigue funcionando igual porque los nombres son idénticos.
