# Prompt para Replit Agent

Copiá y pegá todo el bloque de abajo tal cual en el chat de Replit Agent.

Este prompt REEMPLAZA el enfoque anterior (la función `isLikelyFollowUp` basada en
heurísticas de overlap de keywords / términos en el fragmento / regex de preguntas
referenciales). Se probó en producción dos veces (con "ATR" y con "SuperTrend") y
sigue sin detectar seguimientos naturales de conversación — el problema de fondo es
que cualquier heurística basada en reglas fijas se queda corta ante la variedad real
de cómo la gente hace preguntas de seguimiento.

El nuevo enfoque: en vez de que el código decida de antemano si el mensaje es o no
un follow-up, dejamos que **Groq decida**, dándole siempre el fragmento cacheado del
turno anterior como contexto disponible. Si Groq puede responder con eso, responde
directo. Si no le alcanza, lo dice explícitamente y el código cae al flujo normal de
búsqueda — sin heurísticas previas de clasificación.

// ── Intento con contexto cacheado — Groq decide si alcanza o necesita buscar ──
// En vez de una heurística previa que clasifica "es follow-up / no es follow-up",
// si hay un fragmento del turno anterior SIEMPRE se lo ofrecemos a Groq como
