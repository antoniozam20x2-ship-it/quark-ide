ser expandibles: el textarea del Chat (ClaudeChat.tsx) y el textarea 
del Quark Agent (QuarkAgent.tsx). Actualmente ambos tienen altura fija 
lo que limita escribir prompts largos.

Para CADA textarea, aplicar el mismo patrón:

1. Cambiar el elemento:
   - De: <textarea rows={1} ...> o altura fija en style/className
   - A: textarea con ref + auto-resize por contenido

2. Agregar el ref y el efecto:
   const textareaRef = useRef<HTMLTextAreaElement>(null)
   
   useEffect(() => {
     if (textareaRef.current) {
       textareaRef.current.style.height = 'auto'
       textareaRef.current.style.height = 
         Math.min(textareaRef.current.scrollHeight, 200) + 'px'
     }
   }, [inputValue]) 
   // usar el nombre del estado actual del input en cada componente

3. Aplicar al textarea:
   ref={textareaRef}
   style={{ 
     minHeight: '44px',
     maxHeight: '200px', 
     resize: 'none',
     overflowY: 'auto'
   }}

4. Comportamiento en Enter:
   - Enter solo → envía el mensaje (comportamiento actual, no cambiar)
   - Shift+Enter → salto de línea (agregar si no existe)
   
   onKeyDown={(e) => {
     if (e.key === 'Enter' && !e.shiftKey) {
       e.preventDefault()
       handleSend() // usar el nombre de la función actual
     }
   }}

5. Al enviar el mensaje (en handleSend o equivalente):
   - Resetear altura: 
     if (textareaRef.current) {
       textareaRef.current.style.height = '44px'
     }
